### Week 5 Objectives:

* Study AWS resource access management, security, and operations automation.
* Practice Infrastructure as Code, system management and application deployment.
* Study VPC network connectivity, security monitoring, backup and data storage on AWS.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | - Practice EC2 access management with IAM combined with Tags; study AWS Systems Manager to manage services and automate tasks, and use Session Manager to access and manage sessions. <br> - Study how to initialize and manage AWS infrastructure as code (Infrastructure as Code) with AWS CloudFormation. | 12/10/2026 | 12/10/2026 | [https://cloudjourney.awsstudygroup.com/](https://cloudjourney.awsstudygroup.com/) |
| 2 | - Study and set up Single Sign-On (Amazon SSO) for AWS Organizations. <br> - Practice limiting user permissions with IAM Permissions Boundaries and restricting IAM Role transfer with conditions in policy. | 13/10/2026 | 13/10/2026 | [https://cloudjourney.awsstudygroup.com/](https://cloudjourney.awsstudygroup.com/) |
| 3 | - Practice checking security standards and consolidating security findings with AWS Security Hub; study how to protect applications and APIs with AWS WAF. <br> - Study and set up backup plans, manage resource backups with AWS Backup. | 14/10/2026 | 14/10/2026 | [https://cloudjourney.awsstudygroup.com/](https://cloudjourney.awsstudygroup.com/) |
| 4 | - Study and practice connecting VPCs with VPC Peering to support communication between private virtual networks. <br> - Study AWS Transit Gateway to centrally manage connections between multiple VPCs and related networks. | 15/10/2026 | 15/10/2026 | [https://cloudjourney.awsstudygroup.com/](https://cloudjourney.awsstudygroup.com/) |
| 5 | - Practice deploying applications with Docker and using AWS CodePipeline to build automated application deployment pipelines. <br> - Study AWS Storage Gateway – File Gateway to connect file storage environments with AWS, supporting storage and access to data on the cloud. | 16/10/2026 | 16/10/2026 | [https://cloudjourney.awsstudygroup.com/](https://cloudjourney.awsstudygroup.com/) |

### Week 5 Achievements:

* Understood how to manage EC2 access with IAM and Tags, limit permissions with Permissions Boundaries and control IAM Role transfer with conditions.
* Studied Single Sign-On with Amazon SSO and system management with AWS Systems Manager, Session Manager.
* Understood Infrastructure as Code principles and how to use AWS CloudFormation to initialize and manage infrastructure.
* Grasped the role of AWS Security Hub in security checks, AWS WAF in protecting applications/APIs and AWS Backup in backup management.
* Understood how to connect VPCs with VPC Peering and manage centralized network connectivity with AWS Transit Gateway.
* Practiced deploying applications with Docker, studied CI/CD processes and automated deployment with AWS CodePipeline.
* Studied AWS Storage Gateway – File Gateway and how to integrate file storage with AWS Cloud.

### Week 6 Objectives:

- Explore AWS storage and data management solutions, including Amazon FSx for Windows and building a Data Lake to centralize data from multiple sources.
- Study advanced Amazon DynamoDB architectures, how to organize data and choose the design appropriate for application access requirements.
- Explore AWS cost optimization methods through Savings Plans, Reserved Instances and Reserved DB Instances. Learn how to select appropriate EC2 configurations and track resource usage costs.
- Learn how to use AWS Glue and Amazon Athena to process, query and analyze cost data, thereby supporting effective budget tracking and management.
- Get familiar with the process of migrating from monolithic applications to microservices architecture, and learn how to automate application release and deployment processes.
- Understand the purpose of restructuring data and workflows to improve maintainability, reduce complexity, and support system scalability.

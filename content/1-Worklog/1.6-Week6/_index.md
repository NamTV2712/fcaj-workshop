### Week 6 Objectives

- Explore AWS storage and data management services, including Amazon FSx, Data Lakes, and Amazon DynamoDB.
- Learn cost optimization methods, suitable resource selection, and AWS usage cost monitoring.
- Become familiar with AWS Glue, Amazon Athena, and the migration of monolithic applications.
- Explore microservices, automated application releases, and improvements to data structures and workflows.

### Week 6 Achievements:

- Gained a better understanding of Amazon FSx, Data Lakes, and Amazon DynamoDB, along with data management options on AWS.
- Learned about AWS cost optimization, EC2 right-sizing, and cost monitoring.
- Became familiar with AWS Glue, Amazon Athena, and the key concepts involved in monolithic application migration.
- Improved understanding of microservices architecture and automated application release processes.
- Understood how data and workflow refactoring can improve system maintenance, development, and scalability.

Build a TINA meetings test environment in your own AWS account using CloudFront, an internal ALB, ECS Fargate, RDS PostgreSQL, Valkey, S3 and ECR. Create images from the pinned source commit and use CloudFormation, the CLI and a few AWS Console steps. This walkthrough has not yet been rehearsed from an empty account. Full workspace/agent and voice features are not included.
